# Customer Discovery Execution Kit

**Status:** READY FOR FOUNDER EXECUTION — operational preparation only. No interviews, responses, or willingness-to-pay have been fabricated.
**Canonical context:** `AGENTOS_OPERATING_PROMPT.md` §19-20, §23-26; `AGENTOS_STATE.md`.
**Existing references:** `docs/phase5-*` (plans, templates, target lists, messages, interview briefs, scorecards, wedge scoring).

## Objective
Everything needed for the founder to begin real customer conversations against the treasury governance demo artifact.

## Required flow
1. Choose hypothesis to test first (A: agent action governance / B: manufacturing / C: semiconductor).
2. Select 5-10 targets per chosen wedge from `docs/phase5-outreach-target-list.md` and expanded lists.
3. Run outreach messages from `docs/phase5-outreach-ready-package.md` / phase5h/i/j follow-ups.
4. Use the interview script from `docs/phase5-interview-script.md` (adapted to the chosen wedge).
5. Capture evidence per interview into the tracking template (`docs/phase5-interview-tracking-template.md`) and scorecard (`docs/phase5-five-customer-scorecard.md`).

## Qualification criteria (minimum bar to count as a real signal)
- Real human at a real company in a relevant role.
- Describes a recurring problem with a current workaround/cost (medium) or a budgeted/urgent initiative (strong).

## Scoring rubric
Use `docs/phase5-wedge-scoring.md` factors. Weigh evidence strength per the operating prompt §25 (weak/medium/strong) rather than stated interest.

## Evidence capture format
Record per interview: company, industry, role, problem, frequency, severity, financial impact, workaround, tools, buyer, budget, urgency, AI usage, security concerns, integration needs, desired outcome, pilot willingness, payment willingness, direct quotes, confidence.

## Gate
Proceed to substantial development only after ≥5 real conversations + recurring problem + workaround/cost + plausible buyer + credible pilot/WTP signal (or explicit founder override).

## Hand-off
This kit is complete and ready; the coding agent cannot perform external outreach. Founder executes and feeds back evidence.
